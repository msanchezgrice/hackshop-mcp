# Tag Vocabulary (closed set)

These are the only tags valid for `idea_fit_tags` in `catalog.json`. Adding a new tag requires editing this file. The server validates catalog tags against this list at boot — boot fails on drift.

## Output / Display
- `display` — has a screen (any kind)
- `framed-art` — picture-frame form factor, wall-mount
- `e-ink` — low-power monochrome / color-e-ink display
- `ambient` — peripheral visual presence, not foreground

## Audio
- `voice` — input/output for speech
- `audio-out` — speakers / line-out
- `drone` — sustained ambient soundscape capable

## Input
- `input` — buttons, dials, sensors as user input
- `kiosk` — locked-down single-purpose interface
- `wearable` — body-worn

## Sensors / Smart Home
- `sensor` — environmental sensing (motion, temp, light)
- `bulb` — controllable lighting
- `color-cycle` — RGB / programmable color animation

## Compute
- `sbc` — single-board computer (Pi-class)
- `mini-pc` — x86 small-form-factor
- `low-power` — battery-friendly, sub-1W ideal

## Form / Use
- `retrogaming` — handheld / console for emulation
- `handheld` — battery, portable
- `network` — router/switch repurposing
- `iot` — small connected device
- `peripheral` — USB or aux to other compute
- `educational` — kid/learning oriented
- `industrial` — heavy-duty, repurposable
- `creative-coding` — pixel art, generative output
